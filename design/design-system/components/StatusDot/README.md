# StatusDot

Pulsing accent dot with a mono label - "open to work". Used in the header (desktop), under the tagline (phones) and as the last neofetch row.

- Dot 8px (7px inside cards), `radius-full`, `accent`, `kd-pulse`.
- Label mono 13px `muted` (in neofetch: `text-body`).
- Label text stays English in all languages.

```html
<span class="kd-status"><span class="kd-dot kd-pulse" aria-hidden="true"></span>open to work</span>
```
